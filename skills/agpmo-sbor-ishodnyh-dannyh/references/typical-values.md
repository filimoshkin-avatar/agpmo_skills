# Ориентиры типовой практики

Таблицы ниже — ориентиры навыка для случая, когда ни документы, ни клиент значения не дали. Это не данные клиента: каждое значение отсюда записывается как `assumption` с `basis: typical`, с диапазоном из таблицы и пометкой «ориентир навыка». Если есть учёт клиента, его оценка или регламентный норматив, ориентир не используется. Клиенту ориентиры как «правильные ответы» не предлагаются: на вопрос клиент отвечает своими словами, а ориентир нужен агенту, когда ответа нет.

Ориентиры собраны для российских компаний с проектным офисом на 2026 год и при необходимости правятся исполнителем модели. Регион и отрасль сдвигают оклады заметно, поэтому диапазон обязателен.

## Оклады ролей, тыс. ₽ в месяц до вычета налога

| Роль | Ориентир | Диапазон |
|---|---|---|
| Администратор проекта, секретарь проектного офиса | 100 | 70–130 |
| Специалист проектного офиса, аналитик портфеля | 160 | 110–210 |
| Руководитель проекта | 230 | 160–300 |
| Руководитель проектного офиса, руководитель портфеля | 320 | 220–420 |
| Эксперт функционального подразделения (финансы, закупки, право) | 200 | 140–260 |

Оклад из этой таблицы пиши в той же фразе с пометкой «по типовой практике» или «ориентир навыка»: так проверка выдачи отличает ориентир от оклада конкретного человека. Ставка в час — по нормативам метода: `оклад × 1,3 × 1,2 / 165`. Для администратора по ориентиру это около 945 ₽ в час, для руководителя проекта около 2 175 ₽.

## Трудоёмкость типовых результатов, активные часы по всем ролям

| Результат | Ориентир, ч | Диапазон, ч |
|---|---|---|
| Статус-отчёт по проекту (сбор сведений, сверка, текст) | 4 | 2–6 |
| Протокол совещания с решениями и поручениями | 1,5 | 1–3 |
| Подготовка к совещанию (повестка, материалы) | 1 | 0,5–2 |
| Обработка одного поручения (запись, напоминания, отметка исполнения) | 0,3 | 0,2–0,5 |
| Проверка документа проектным офисом (паспорт, отчёт, запрос на изменение) | 2 | 1–4 |
| Пакет документов к воротам стадии (сбор и проверка комплектности) | 8 | 4–12 |
| Регистрация и первичный разбор запроса на изменение | 1 | 0,5–2 |
| Оценка инициативы или заявки на проект | 5 | 3–8 |
| Сводный отчёт по портфелю | 12 | 8–24 |

## Частоты, если регламента и учёта нет

| Событие | Ориентир | Диапазон |
|---|---|---|
| Совещание по проекту | 4,33 в месяц (еженедельно) | 2–4,33 |
| Статус-отчёт по проекту | 1 в месяц | 1–4,33 |
| Запрос на изменение | 0,5 в месяц на проект | 0,2–1,5 |
| Сводный отчёт по портфелю | 1 в месяц на портфель | 0,33–1 |
| Поручений с одного совещания | 4 | 2–8 |

## Что из ориентиров не следует

Доли ошибок текущего процесса, цена случая, изменённые решения и денежная реализация времени по ориентирам не задаются: без сведений клиента они в базе равны нулю, а верхние оценки записываются в сценарии с описанием механизма (`references/model-and-output.md`).
