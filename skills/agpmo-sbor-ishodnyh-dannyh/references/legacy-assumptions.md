# Значения каталога v1

Исполнитель модели заполняет этими значениями неизвестные характеристики агентов и затраты для первого расчёта, с пометкой «допущение». Агент клиента их не переносит в факты клиента, не предлагает клиенту как ориентиры и не использует для ранжирования практик. Для собственной практики значения берутся по образцу из поля `analog`, если он указан.

Контур и офис:

| Ключ | Параметр | Единица | Группа | По умолчанию |
|---|---|---|---|---|
| P | Проектов в контуре | шт. | Факты | число активных проектов по реестру; без реестра 30 (В) |
| r | Полная стоимость часа сотрудника | ₽ за час | Факты | 3 500 |
| H | Горизонт оценки и амортизации | мес. | Решения | 24 |
| ca | Результативность проверки: доля существенных ошибок, которую снимает проверка человека | % | Агент | 80 |
| platOps | Общая платформа: агенты, шлюз к моделям, наблюдаемость, безопасность | тыс. ₽ в месяц | Агент | 600 |
| platImpl | Внедрение платформы: интеграции, общий источник данных, контур безопасности | тыс. ₽ разово | Агент | 6 000 |
| fte | Надзор за агентами | ставок по 165 ч | Решения | 1,5 |
| gap | Интервал запуска следующей практики | мес. | Решения | 2 |
| joint | Дополнительный эффект совместной работы практик, не учтённый ни в одной практике | тыс. ₽ в месяц | Решения | 0 |

Практики. Значения по умолчанию даны в порядке Брифер / Диспетчер / Дозорный / Летописец.

| Ключ | Параметр | Единица | Группа | По умолчанию |
|---|---|---|---|---|
| N | Задач на проект | в месяц | Факты | 8 / 25 / 20 / 40 |
| th | Трудоёмкость задачи у человека, включая постановку и уточнения | ч | Факты | 3 / 0,5 / 1,5 / 0,3 |
| cov | Охват: доля задач, переданная агенту в полном режиме | % | Решения | 80 / 85 / 70 / 90 |
| sv | Доля проверяемых результатов | % | Решения | 100 / 30 / 60 / 20 |
| tv | Время проверки одного результата | мин. | Факты | 15 / 3 / 10 / 2 |
| e0 | Существенные ошибки нынешнего ручного процесса, дошедшие до использования | % задач | Факты | 0 |
| L | Цена пропущенной ошибки | тыс. ₽ | Факты | 150 / 20 / 200 / 20 |
| ds | Результаты, изменившие решение | % результатов | Факты | 0; сценарий 6,3 / 4 / 2,5 / 2,5 |
| v | Предотвращённые затраты на одно изменённое решение | тыс. ₽ | Факты | 0; сценарий 40 / 30 / 150 / 25 |
| real | Реализация высвобождённого времени | % | Решения | 0 без выбранного механизма; сценарий 50 / 40 / 35 / 30 |
| p | Принято без доработки | % | Агент | 75 / 85 / 70 / 90 |
| f | Объём доработки непринятого результата | % трудоёмкости | Агент | 40 / 30 / 50 / 30 |
| ct | Технические затраты на задачу (R × c) | ₽ | Агент | 180 / 40 / 320 / 30 |
| R | Прогонов на задачу | циклов | Агент | 3 / 2 / 4 / 2 |
| c | Стоимость прогона | ₽ | Агент | 60 / 20 / 80 / 15 |
| e | Существенные ошибки агента до проверки | % результатов | Агент | 1 / 1 / 0,5 / 0,5 |
| d | Дублирование: доля высвобождённого времени на параллельную ручную работу | % | Агент | 20 / 30 / 25 / 15 |
| impl | Внедрение практики | тыс. ₽ разово | Агент | 1 500 / 1 200 / 2 500 / 900 |
| ops | Эксплуатация практики без людей, учтённых в надзоре | тыс. ₽ в месяц | Агент | 120 / 100 / 150 / 80 |
| ramp | Выход на полный охват | мес. | Агент | 4 / 3 / 6 / 3 |

Для ds, v, real и joint базовое значение без подтверждения равно нулю. Сценарные значения ds и v из таблицы исполнитель модели может использовать как верхний вариант только для практик каталога и только с пояснением; сценарные значения реализации времени из таблицы импорт не использует вовсе: набор «Время в деньги» строится только из ключей `scenario.<практика>.real` пакета, а без них исполнитель может задать его вручную с пояснением механизма. Значения `N` и `th` каталога заменяют только неизвестные; ориентиры типовой практики для агента клиента — в `typical-values.md`. Агент клиента их в выжимку не переносит.

Образец «Эксперт» (`expert`) — только для поля `analog` собственной практики проверки документов; значения оценены исполнителем и уточняются на пилоте:

| Ключ | По умолчанию |
|---|---|
| N | 1 |
| th | 3 |
| cov, sv, tv | 70 %, 100 %, 20 мин |
| e0, L | 0, 100 тыс. ₽ |
| ds, v, real | 0; сценарий 1,5 % / 100 тыс. ₽ / 35 % |
| p, f | 70 %, 40 % |
| R, c, ct | 3, 80 ₽, 240 ₽ |
| e, d | 1 %, 25 % |
| impl, ops, ramp | 1 800 тыс. ₽, 120 тыс. ₽ в месяц, 4 мес. |
