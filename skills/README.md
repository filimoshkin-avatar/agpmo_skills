## Пересборка процесса вокруг агентов

**Версия:** 1.7
**Идентификатор:** `peresborka-processa-vokrug-agentov`
**Инструкция:** [SKILL.md](peresborka-processa-vokrug-agentov/SKILL.md)

Помогает пересмотреть рабочий процесс и спроектировать его выполнение с участием ИИ-агентов, сохраняя полезный результат и обязательные ограничения.

### Когда использовать

- Нужно пересобрать процесс, услугу или регламент вокруг агентов.
- Требуется сравнить существующий процесс с вариантами нового.
- Нужно определить функции агентов, их полномочия и точки участия человека.

### Как работает

Принимает описание процесса: рассказ, регламент, договор, схему или набор документов. Проводит владельца через четыре согласования: текущий процесс и результат, идеи и ограничения, выбор варианта, агенты и полномочия. Оценки сокращения трудозатрат требуют проверки до внедрения.

### Результат

HTML-листы согласований со схемами и итоговый HTML-отчёт с выбранным вариантом процесса, функциями агентов, ограничениями и планом проверки.

### Состав и требования

- `SKILL.md` — основная инструкция.
- `references/` — методика, требования к схемам и отчётам, совместимость и условия приёмки.
- `scripts/draw_process.py` — генератор схем и отчётов.
- `examples/` — примеры входных JSON-файлов.
- `CHANGELOG.md` — история изменений.

Для генератора нужен Python 3.8+; по описанию автора сторонние пакеты и сеть не требуются. Без Python предусмотрены текстовые схемы Mermaid или таблицы. Для использования перенесите всю папку навыка в каталог навыков вашей агентной среды, сохранив структуру.

## Сбор исходных данных AgPMO

**Версия:** 5.0
**Идентификатор:** `agpmo-sbor-ishodnyh-dannyh`
**Инструкция:** [SKILL.md](agpmo-sbor-ishodnyh-dannyh/SKILL.md)

Разбирает материалы клиента, выявляет потери и задачи для агентного проектного офиса, подбирает предварительный состав практик и готовит исходные данные для финансовой модели. Не заменяет сам расчёт финансовой модели.

### Когда использовать

- Нужно подготовиться к оценке экономики и окупаемости AgPMO.
- Требуется разобрать документы клиента и обосновать выбор практик.
- Нужно собрать проверяемые исходные данные с минимумом уточнений.

### Как работает и что выдаёт

Принимает документы пачками на любом этапе; при отсутствии документов работает с ответами клиента. Отделяет факты от допущений, связывает выводы с источниками и задаёт существенные уточнения с видимым счётом. Результат: обезличенная выжимка и пакет данных для исполнителя финансовой модели.

### Состав и требования

- `SKILL.md` — основная инструкция.
- `references/` — правила работы с источниками, вопросы, подбор практик, формат выдачи и ручные проверки.
- `scripts/inventory_sources.py` — инвентаризация материалов.
- `scripts/validate_case.py` — проверка подготовленного случая.
- `scripts/export_case.py` — экспорт результата.

Скрипты рассчитаны на Python 3; по описанию автора сторонние библиотеки, сеть и ключи доступа не требуются. Без Python предусмотрены ручные проверки. Для использования перенесите всю папку навыка в каталог навыков вашей агентной среды, сохранив структуру.
