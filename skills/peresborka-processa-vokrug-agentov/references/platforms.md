# Среды выполнения

Ядро навыка переносимо: SKILL.md, справочники и скрипт на стандартной библиотеке Python не зависят от платформы. Схемы и файлы выдаются по возможностям среды. Переносимость не означает одинакового качества: качество разговора и проектирования зависит от модели, поэтому проверенные сочетания платформ и моделей перечислены в конце, а перед работой на новом сочетании стоит пройти сценарии из `references/acceptance.md` (файл есть в архиве навыка).

## Как найти папку навыка

Скрипт лежит в `<папка навыка>/scripts/draw_process.py`, где папка навыка — каталог загруженного SKILL.md. Запускай его по абсолютному пути: рабочая папка агента обычно другая.

| Среда | Как узнать папку навыка |
|---|---|
| OpenClaw | в тексте навыка заполнитель `{baseDir}` разрешается в каталог навыка; в песочнице навык читается из материализованной копии, путь берётся оттуда же |
| Hermes Agent | `${HERMES_SKILL_DIR}` в тексте навыка заменяется абсолютным путём; сообщение активации содержит строку «[Skill directory: /абсолютный/путь]»; если подстановка выключена настройкой `skills.template_vars: false`, бери путь из сообщения активации |
| Claude (Claude Code, приложение Claude, агенты на Claude Agent SDK) | путь виден в сообщении о загрузке навыка; если его нет, найди `draw_process.py` поиском по имени в доступных папках |
| Другие среды со стандартом Agent Skills | каталог, из которого загружен SKILL.md; ссылки внутри навыка относительные от этого каталога |

Если путь установить нельзя, считай, что скрипта нет, и переходи к запасным видам схем.

## Выдача файлов

Показывай человеку то, что его канал действительно отображает, и не ссылайся на пути песочницы, которых он не видит. На каждом согласовании отправляй HTML-лист согласования, в конце — HTML-отчёт: файлы открываются в браузере компьютера и телефона без интернета. Картинки схем в переписку не отправляй и файлы в архивы не упаковывай: владелец должен открыть лист одним нажатием.

- Среда с просмотром файлов (приложение Claude, веб-интерфейсы): лист или отчёт — файлом; документ и файлы схем — по просьбе.
- OpenClaw и мессенджеры: HTML-файл отправляй документом; сообщение — две строки прогресса, суть в двух-трёх фразах и вопрос с вариантами ответа, чтобы ответить можно было, не открывая файл.
- Hermes Agent: файлы уходят вложениями, если в ответе есть директива `[[as_document]]` (обычно последней строкой).
- Канал не принимает файлы: суть листа и вопрос — в сообщении, схема — текстом Mermaid, если канал его показывает, иначе таблица «дорожка × этап».

## Ограниченные среды

| Ситуация | Что делать |
|---|---|
| Нет Python | листы согласования и отчёт не собираются: маршрут, строки прогресса и вопросы те же, суть листа — в сообщении, основная часть — в документе; Mermaid вручную по образцу из `references/diagram-spec.md`; если канал не показывает Mermaid — таблица «дорожка × этап» |
| Нет просмотра изображений | ноль нарушений и замечаний скрипта — лучшая доступная проверка; одним абзацем перескажи, что показывает схема |
| Нет записи файлов | состояние работы — коротким блоком в конце сообщения на каждом согласовании; документ — в сообщениях по разделам; схема — Mermaid или таблица |
| Нечитаемый формат (docx, pdf, скан) | назови файл и попроси текст или другой формат только по нему; остальное продолжай |
| Малый контекст (локальные и компактные модели) | справочники читай только нужными разделами; длинные документы разбирай по частям и записывай факты в файл состояния; спецификацию схем и описание отчёта пиши сразу в файлы; держи один вопрос на согласование |
| Нет сети | сеть навыку не нужна |

## Установка

- OpenClaw: папку `peresborka-processa-vokrug-agentov` положи в каталог навыков рабочего пространства (`<workspace>/skills/`) или личный каталог (`~/.agents/skills/`). Имя папки совпадает с полем `name`.
- Hermes Agent: папку положи в каталог навыков Hermes по его документации; дополнительных переменных окружения навык не требует.
- Claude Code: `~/.claude/skills/` или `.claude/skills/` проекта. Приложение Claude: загрузить архив навыка в настройках навыков.
- Среды, где навык — один файл: однофайловая версия содержит справочники и скрипт в приложениях; скрипт из приложения сохрани в `draw_process.py` без изменений.
